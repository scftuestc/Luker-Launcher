**改动**

- `707dd44`：退出线程创建失败时主线程同步 `process.stop_all()`，`finally` 退出；测试断言 `stop_all_calls == 1`。
- `16dbd3f`：`widget_scaling()`；`winfo_*` 先除以缩放；`_character_display_scale` 纳入缓存键；补 125%/150% 测试。
- `3966429`：`launcher.spec` 的 `datas` 目标目录断言；`check.bat` 失败传播测试；`test_theme_assets` 改容差；`check.bat` 五道门禁改 `call python`。

- `6a1f2fb`：删除未使用的 `_theme_cards`。

- `3ad154f`：组合根回调空值保护。

**验证**

- [已验证] `check.bat` 通过；修复记录称 756 项测试、覆盖率 74%；ruff/mypy 通过。
- [已验证] DPI 修复前 150% 得到 `(388,517)`，修复后 `(256,341)`；100%/125%/150% 视觉冒烟通过（模拟缩放，当前机器 100%）。
- [已验证] `check.bat` 失败传播测试暴露真实问题：`.bat` 包装器不返回；已用 `call` 修复。

**决策/风险**

- 退出失败路径接受主线程同步停止，可能阻塞数秒。
- 收窄异常后，某些损坏图片会多一条 warning；这是预期。

**遗留**

- 真实 125%/150% 设备、发布 bump/构建（OPEN-01/02/03）。
