## 快照边界

- `00` 是 2026-11-14 的详细手册快照；其中 §0 的旧规则（如“本文件在 `.zcode/` 下、不进入版本库”）已被主手册 §0 取代。

- 归档不更新；新日志只写主手册。

## 维护规则

- **不修改归档正文**；发现错误在主手册 §0.9 记勘误，并引用旧条目。
- **新日志只写主手册 §10**；归档不追加。
- **轮转**：主手册 §10 超过 30 条或主版本结束时，把较早条目的详细内容迁到 `docs/archive/05-...`，并更新本索引。
- **权威顺序**：代码/测试/README > 主手册 > 本归档 > 本地报告。
