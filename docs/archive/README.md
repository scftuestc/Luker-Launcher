1. 冻结当前分册；不再改正文。
2. 新建 `docs/archive/05-<版本段>-<主题>.md`，把较早条目的详细正文迁入。
3. 主手册 §10.2 保留摘要和链接；§10.3 只留未归档条目。
4. 更新 `INDEX.md`、本 README 的分册表/frontier、主手册 §10.1/§10.2。
5. 跑文档校验器；检查 DEV ID 唯一、链接、条目计数。
6. 按批次提交；作者/签名遵循主手册 §0.5。
