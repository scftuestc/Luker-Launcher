## 1. 项目基线

### 1.1 产品是什么

Luker Launcher 是 Windows 10/11 x64 上的**常驻托盘启动器**，不包含 Luker 本体。它负责：

- 一键启动、停止、重启 Luker（`node server.js`）；
- 实时读取并显示 Luker 输出日志；
- 服务就绪后自动打开 PWA/浏览器；
- 托盘图标、托盘右键菜单、关闭窗口行为；
- 主题、毛玻璃、窗口圆角、动效；
- Luker 版本检查与 Git 更新；
- 单实例、子进程兜底清理、文件日志。

Luker 是基于 SillyTavern 的 LLM 前端；启动器只要求目录包含 `Start.bat`、`server.js`，并从 `config.yaml` 读取端口。
