# Windows 手动冒烟清单

发布前除 `check.bat` 外，按本清单在真实 Windows 桌面执行一次。原生调用、
托盘、DPI 和进程相关改动不能只依赖 mock 测试。

## 前置

- 使用临时目录或 Luker 副本，不要在主安装上验证更新流程。
- 记录 Windows 版本、架构、DPI 和显示器布局。
- 先执行 `check.bat`，确认格式、lint、类型、测试和覆盖率全部通过。

## 托盘

- [ ] 启动后通知区域出现 Luker 图标。
- [ ] 左键单击显示日志窗口，再次单击隐藏。
- [ ] 右键菜单在正确位置弹出，不抢焦点。
- [ ] 键盘 `↑` / `↓` / `Home` / `End` 移动高亮，`Enter` 执行，`Esc` 关闭。
- [ ] 菜单打开时点击外部会收起，且不把焦点抢回菜单。
- [ ] 重启 Explorer 后托盘图标自动恢复。
- [ ] 退出后托盘图标消失，无残留图标。

## DPI 与多屏

- [ ] 100%、125%、150%、200% 缩放下窗口和菜单不裁切、不模糊。
- [ ] 拖到负坐标副屏，设置窗口、日志窗口和托盘菜单仍出现在光标所在屏幕。
- [ ] 跨屏移动后最小化/恢复，窗口回到原显示器。
- [ ] 修改显示缩放或插拔显示器后，重新打开窗口尺寸正常。

## 主题与窗口

- [ ] 切换所有主题，图标、文字、边框和日志颜色跟随主题。
- [ ] 雾灰主题没有“毛玻璃”开关，窗口不透明。
- [ ] 其他主题可开关毛玻璃，开启时窗口半透明且文字可读。
- [ ] 设置窗口显示“启动路径”，路径选择和校验正常。
- [ ] “检查更新”下方没有默认提示文案。
- [ ] 日志换行后与正文起点对齐，时间戳格式不变。

## 启动、停止与退出

- [ ] 首次选择 Luker 路径后可正常启动；取消选择时有提示并退出。
- [ ] 启动后 Luker 服务可访问，状态灯进入“运行中”。
- [ ] 停止后端口释放，任务管理器没有残留 `node` 进程。
- [ ] 重启 Luker 后日志窗口和托盘状态同步。
- [ ] 关闭行为 `ask` / `tray` / `exit` 均符合设置；托盘不可用时关闭仍会确认。
- [ ] 退出后启动器进程、托盘图标和 Luker 子进程全部结束。

## 沉浸应用模式

- [ ] 自动打开只发生一次。
- [ ] 自动打开等待期间手动点击“Luker 页面”，不会再次自动打开。
- [ ] 找不到 Edge 或 PWA 时回退到默认浏览器，日志中有明确提示。
- [ ] APPX / `--app-id` / `--app` 三种启动路径按环境正常回退。

## 更新

- [ ] 在 Luker 副本上检查更新，能显示发行版和最新提交。
- [ ] 更新前有明确确认，更新后依赖安装成功并自动重启。
- [ ] 制造失败（如断网或占用文件）时能回滚到原版本。
- [ ] 更新完成后按钮状态和日志正确。

## 打包 exe

- [ ] `Luker-Launcher.exe` 能启动，版本信息和图标正确。
- [ ] 重复托盘、DPI、主题、启停、退出关键项。
- [ ] 关闭 `check.bat` 后再次确认配置文件未被测试修改。
